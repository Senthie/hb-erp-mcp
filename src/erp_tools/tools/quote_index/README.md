# `query` — 客户报价需求【列表】查询 / 导出 CSV

> 页面：`/Admin/BaoJia/BJ_KHBJXQ/Index.aspx?QXID=876&IsAdd=1&LoginUserID=<uid>`
> 用途：按日期/客户/业务员/任意条件筛单据，导出 CSV，拿到 `记录ID` 后可再去 `quote` 取详情。

## 命令

```powershell
.\.venv\Scripts\erp.exe query [选项]
```

`erp query` 必须已登录（首次会自动读 `cookies/`，失效则走登录流程）。

## 选项

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--from YYYY-MM-DD` | 本月 1 号 | 制单起始日期（服务端过滤，**必填项**，留空会被服务端忽略） |
| `--to YYYY-MM-DD` | 今天 | 制单结束日期 |
| `--key 文本` | 空 | 服务端关键字（配合 `--field`） |
| `--field 中文名` | 页面默认 | 关键字字段：表单编号 / 客户名称 / 产品名称 / 香港单号 / 业务员 / 规格 / 款数… |
| `--where 表达式` | 空 | 本地多条件过滤，逗号分隔，见下表 |
| `--customer 文本` | 空 | 等价 `--where 客户名称~文本` |
| `--sales 文本` | 空 | 等价 `--where 业务员~文本` |
| `--status 文本` | 空 | 等价 `--where 报价状态~文本`（需求审批 / 报价审批…） |
| `--columns a,b,c` | 全部 | 只导出指定列 |
| `--out 路径` | 无 | 导出 CSV（`.jsonl` 结尾则写 JSONL） |
| `--jsonl 路径` | 无 | 额外写一份 JSONL |
| `--limit N` | 不限 | 最多返回 N 条（过滤后截断） |
| `--page-size N` | 5000 | 每页记录数，调大通常一页取全 |
| `--max-pages N` | 200 | 翻页安全阀，超过即报错 |
| `--dry-run` | 关 | 只打印条件与命中数，不写文件 |

`--where` 运算符：

| 运算符 | 含义 | 示例 |
| --- | --- | --- |
| `~` | 包含（忽略大小写） | `客户名称~ADG` |
| `=` / `!=` | 等于 / 不等于 | `报价状态=需求审批` |
| `>=` `<=` `>` `<` | 比较（数字按数值、日期按字面） | `数量描述>=5000`、`制单日期>=2026-11-01` |

字段名支持唯一子串匹配（`客户` → `客户名称`）；写错会报错并列出可用列。

## 示例

```powershell
# 本月全部，导出 CSV
erp query --out out\list.csv

# 客户 + 状态
erp query --customer IBL --status 需求审批 --out out\ibl.csv

# 服务端关键字（减少传输量）
erp query --from 2026-11-01 --to 2026-11-30 --key BJXQ2611 --field 表单编号

# 任意多条件 + 指定列
erp query --from 2026-01-01 --to 2026-11-06 `
    --where "制单人!=李东员,数量描述>=5000" `
    --columns "表单编号,客户名称,产品名称,数量描述,记录ID" --out out\q.csv

# 只看命中数
erp query --where "报价状态~需求审批" --dry-run

# 单号精确定位（拿到记录ID 后交给 quote）
erp query --from 2026-11-05 --to 2026-11-05 --key BJXQ261105013 --field 表单编号 --out out\one.csv
```

## 输出格式

### CSV（`--out xxx.csv`）

- 编码 **utf-8-sig**（Excel 双击不乱码）
- 单元格里的换行压成空格
- 默认 36 列 = 页面 38 列去掉 `选择/信息/打印`，末尾追加 `记录ID`

```

客户名称,业务员,产品类别,产品名称,规格,单位,最小值,中间值,最大值,款数,语言数,客户目标价,

客户反馈描述,包装方式,修改记录,记录ID
```

| 列 | 说明 |
| --- | --- |
| `表单编号` | 如 `BJXQ261105013`，可喂给 `erp quote --bdbh` |
| `记录ID` | 主记录 GUID，可喂给 `erp quote --id` / `--csv` |
| `报价状态` | 需求审批 / 报价审批 / … |
| `数量描述` | 页面上的数量汇总列（文本，注意可能带单位） |
| `制单日期` | `YYYY-MM-DD HH:MM:SS` |

## Python API

```python
from erp_tools.api import connect, query_quotes

auth = connect(username="21146", password="***")
rows = query_quotes(auth, from_date="2026-11-01", to_date="2026-11-06",
                    where="报价状态~需求审批", limit=50)
print(rows[0]["记录ID"], rows[0]["表单编号"])
```

需要更细控制时直接用工具类：

```python
from erp_tools.tools.quote_index import QuoteListTool

tool = QuoteListTool(auth)
row = tool.find_by_bdbh("BJXQ261105013")      # 单号 -> 列表行（含记录ID）
rows, headers, page = tool.collect(from_date="2026-11-01", where="客户名称~IBL")
```

## 协议要点 / 坑

- 表单**不硬编码**：先 GET 页面把整张 `form1` 快照，再覆盖日期/关键字/页大小，ERP 加字段不用改代码。
- 结果在 `div#gViewDiv > table#gridView`，第 1 行 `tr.FixedTitleRow` 是 38 列表头。
- 主记录 ID 只认 `OnDBClickOpenData('<ID>',…)` / `showMessagePop('<ID>')`，
  行内还有子表 GUID，按「第一个 GUID」取会打不开详情页。
- **日期范围必填**：留空时服务端套默认区间并忽略关键字。
- 查不到时返回一行全空占位（`OnDBClickOpenData('')`），解析时已丢弃。
- 分页用 `__EVENTTARGET=btnNext` 全量回发（本页实测有效）。
