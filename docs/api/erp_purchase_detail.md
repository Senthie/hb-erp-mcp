# `erp_purchase_detail` — 采购订单【详情】

> 页面：`CaiGou/CG_CGDD/Add.aspx?id=<记录ID>&Option=3&QXID=266`
> CLI：`erp purchase-detail --id <ID>` 或 `--no CGDD261118031`｜**只读**

## 用途

读取一张采购订单的表头字段 + **材料明细内联网格**（`table#gridView2`，33 列）。

## 参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `record_id` | str | `erp_purchase_list` 的 `记录ID` |
| `number` | str | 表单编号（如 `CGDD261118031`），按「单号日期 → 当月 → 本月 → 近一年」反查 |
| `include_texts` | bool | 是否返回备注类文本域（默认 true） |

## 字段说明

- `fields` 里除了业务字段，还有金额汇总（订单总金额 / 已预付 / 可预付）。
- `grids[0]` 就是材料明细；`合计` 行会被丢掉。
- 采购订单**没有弹窗数据子页** —— 明细已经在这张网格里，
  `nodes` 只有「供应商档案选择」这类**选择弹窗**（可用 `erp_purchase_node` 打开）。

## 注意

- 同一张订单多个料号 → 列表里多行、`记录ID` 相同；详情页一次返回全部明细。
