# `erp_purchase_list` — 采购订单【列表】

> 菜单：**采购管理 › 采购订单 › 列表-采购订单**
> 页面：`CaiGou/CG_CGDD/Index.aspx`（QXID **266**）｜CLI：`erp purchase-list`｜**只读**

## 用途

按制单日期区间 / 服务端下拉 / 本地条件筛**采购订单材料明细**并导出。

⚠ **一行 = 一条采购材料明细**，不是一张订单：表单编号 `CGDD` + `YYMMDD` + 流水
（如 `CGDD261118031`），同一张订单的多个料号是多行，所以 `记录ID` 会重复出现。

## 参数

| 参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `from_date` / `to_date` | str | 本月 1 号 / 今天 | 制单日期区间（本页**没有**日期字段下拉） |
| `filters` | dict | — | **服务端**下拉，见下表 |
| `where` | str | — | 本地过滤，如 `表单编号=CGDD261118031` |
| `key` / `field` | str | `""` | 服务端关键字 + 字段中文名（表单编号 / 订单编号 / 材料名称 / 供应商名称 / 材料编码…） |
| `key1` / `field1` | str | `""` | 第二组关键字 |
| `columns` | str | 39 列 | 只返回这些列 |
| `limit` | int | 50 | 1~500 |

### 服务端下拉

| 中文键 | 控件 | 常见值 |
| --- | --- | --- |
| 审批情况 | `txtCheck` | 全部 / 未审批 / 已全审批 / 未全审批 |
| 表单状态 | `txtBDZT` | 全部 / 未入库完 / 入库完 / 入库中 / 未入库 |
| 数据粒度 | `txtSFMX` | 明细数据(0) / 汇总数据(1) |
| 材料类别 | `txtCLLB` | 全部(-1) / 纸料档案(236) / 辅料档案(1135) |
| 是否分生产 | `txtSFFSC` | 全部 / 是 / 否 |
| 是否已过订单 | `txtYGDD` | 全部 / 是 / 否 |
| 标准订单 | `txtBZDD` | 全部 / 是 / 否 |
| 供货方式 | `txtGHFS` | 全部 / 现货 / 期货 |
| 工序排期 | `txtGXPQ` | 全部 / 是 / 否 |
| 入库情况 | `txtSFRK` | 全部 / 入库 / 不入库 |
| 是否不入库 | `txtSFBRK` | 是(1) / 否(0) |

## 返回

```json
{
  "columns": ["材料状态", "订单编号", "供应商名称", "材料名称", "数量", "单价", "金额", "记录ID"],
  "records": [{"表单编号": "CGDD261118031", "材料名称": "…", "记录ID": "e53b58dd-…"}],
  "count": 50,
  "total": 1196,
  "pages": 1,
  "truncated": true,
  "note": "一行 = 一条采购材料明细；同一 表单编号 可能多行"
}
```

## 注意

- 数据量偏大：2026-11-01~18 命中 **1196 行**（一个月的材料明细），
  MCP 默认只回 50 行，取全量请调大 `limit`（上限 500）或直接导出。
- 列表 42 列里有单价 / 金额 / 基准单价，做成本核对时直接取。
- 采购订单**没有新增菜单**（只有列表 + 详情），本工具只读。
