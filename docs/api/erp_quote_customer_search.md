# `erp_quote_customer_search` — 客户资料检索

> 菜单：**业务报价管理 › 业务需求 › 客户报价需求 › 新增-客户报价需求**
> 页面：`Base_Select/Base_KHZL_Select.aspx`（客户资料选择页）｜CLI：—｜**只读**

## 用途

按名称片段模糊检索客户，返回 `customer_id`(GUID)、编码、简称，以及该客户默认的
业务员 / 跟单员 / 折扣率。拿到的 `customer_id` 可直接交给 `erp_quote_create`。

## 参数

| 参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `keyword` | str | `""` | 客户名称 / 简称片段；留空返回前若干条 |
| `limit` | int | 20 | 最多返回几个客户 |

## 返回

```json
{
  "count": 2,
  "customers": [
    { "customer_id": "86f10bff-…", "编码": "01.0603", "简称": "MCP24",
      "名称": "…", "业务员": "颜娟", "跟单员": "肖也", "折扣率": "10" }
  ]
}
```

## 注意

- 匹配是**服务端模糊匹配**，关键词太短会返回很多条，建议带 `limit`。
- 客户默认业务员/折扣率只是默认值，`erp_quote_create` 里显式传参会覆盖。
- 该页与报价需求页共用同一套选择协议（`InputData` + 回发按钮），无额外登录要求。
