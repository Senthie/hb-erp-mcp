# `erp_costing_list` — 产品核价【列表】

> 菜单：**业务报价管理 › 产品核价 › 列表-产品核价**
> 页面：`BaoJia/BJ_KHBJ/Index.aspx`（QXID **1281**）｜CLI：`erp costing-list`｜**只读**

## 用途

筛**核价产品行**并导出。这一页与「列表-客户报价」是**同一个 aspx**，
只是菜单 QXID 不同（860 / 1281），列集也不同：核价页返回 **74 列**，
比报价页多出「核价数量 / 核价单价 / 核价利润率 / 纸张单价 / 辅料单价 / 印前单价 /
印刷单价 / 印后单价 / 版费单价 / 纸箱费单价 / 台版费单价 / 海运费单价 / 其他金额单价 /
纸料金额 / 印刷金额 / 印后金额 / 辅料金额 / 版费 / 纸箱费 / 客户其他费用 / 台版费 /
海运费 / 订单单价 / 币种 / 汇率 / 税率 / 含税金额 / 参数对比 / 来源单号…」这些成本列。

⚠ **一行 = 一个核价产品行**，表单编号 `CPHJ` 开头，同一单号可能多行（`-01/-02`）。

## 参数

| 参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `from_date` / `to_date` | str | 本月 1 号 / 今天 | 日期区间 |
| `date_type` | str | `制单日期` | `制单日期`(ZDRQ) / `交货日期`(KHJHRQ) / `离厂日期`(LCRQ) |
| `filters` | dict | — | **服务端**下拉：审批情况 / 报废状态 / 确认情况 / 签订单 / 客户属性 / 模板 / 报价分类 / 查询方式（值可写中文） |
| `where` | str | — | 本地过滤，`字段~值` / `字段=值`，逗号分隔 |
| `key` / `field` | str | `""` | 服务端关键字 + 字段中文名（表单编号 / 客户名称 / 产品名称 / 订单编号…） |
| `key1` / `field1` | str | `""` | 第二组关键字 |
| `columns` | str | 71 列 | 只返回这些列（`选择/信息/打印` 默认剔除） |
| `limit` | int | 50 | 1~500 |

## 详情与子数据

核价详情与客户报价**完全同一套页面**（`BJ_KHBJ/Add.aspx`），所以不重复实现：

- 详情 → `erp_price_detail`（CLI `erp price-detail`）
- 子数据（数量档 / 部件 / 工序 / 辅料 / 费项 / 20+ 节点）→ `erp_price_node`（CLI `erp price-node`）

## 注意

- QXID 必须显式用 **1281**：菜单探测会落到 860（客户报价），那时拿到的是 56 列的报价列表。
- 实测 2026-11-01~18：45 行。
