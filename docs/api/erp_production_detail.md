# `erp_production_detail` — 生产施工单【详情】

> 页面：`ShengChan/SC_SCSGD/Add.aspx?id=<记录ID>&Option=3&QXID=740`
> CLI：`erp production-detail --id <ID>` 或 `--no SGD2611180011`｜**只读**

## 用途

读取一张施工单的**全部可见数据**（`Option=3` 只读态），并同时告诉你
**这一单还能点开哪些子页**（`nodes`）。

## 参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `record_id` | str | `erp_production_list` 的 `记录ID` |
| `number` | str | 生产单号；给单号时先按「单号里的日期 → 当月 → 本月 → 近一年」反查记录 ID |
| `include_texts` | bool | 是否返回备注类文本域（默认 true） |

`record_id` 与 `number` 至少给一个。

## 字段说明

- `fields`：全文档「标签格 → 右邻格」汇总。同名标签保留**第一个有值**的
  （页面里同一标签会出现多次，例如明细行 / 文本域行 / 汇总行）。
- `grids`：页面上的**内联网格**。施工单这里是两块：
  * 部件表（17 列：部件名称 / P数 / 色数 / 部件尺寸 / 开料尺寸 / 单面P数 / 帖数 /
    拼版方式 / 版材数量 / 材料名称 / 印刷正数 / 分纸加放 …）
  * 送货信息 `gridView`（21 列：序号 / 产品编号 / 产品名称 / 发票类别 / 客户名称 /
    订单编号 / 语言 / 货名代码 / 货名名称 / 送货数量 / 留样数量 / 附送数量 …）
- `texts`：`textarea` 里的备注类长文本（`txtRemark` / `txtCPMX` / `txtQTRemark2..5`）。
  没有 `name` 的 textarea 用 `textarea1..n` 占位。
- `self_check`：详情页里 `lblID` 与我们请求的 `id` 是否一致。ERP 偶尔会「串记录」
  （同一 Cookie 下连续 GET 有时返回上一张单），不一致会自动重试一次。

## 注意

- 详情页有大量 `disabled` 控件与**空 options 的 `<select>`**（`txtBJBJLB`、`txtBJZYFS`），
  回发时必须剔除，否则事件验证直接 500「回发或回调参数无效」——
  这也是 `erp_production_node` 能正常工作的前提。
- 单号反查只看近一年；更早的单据已归档。
