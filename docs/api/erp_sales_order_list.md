# `erp_sales_order_list` — 客户订单【列表】

> 菜单：**客户订单管理 › 客户订单 › 列表-客户订单**
> 页面：`DingDan/DD_KHDD/Index.aspx`（QXID **687**）｜CLI：`erp sales-order-list`｜**只读**

## 用途

按日期区间 / 服务端下拉 / 本地条件筛**客户订单产品行**并导出。

⚠ **一行 = 一个订单产品行**，不是一张订单：表单编号 `KHDD` + `YYMMDD` + 流水
（如 `KHDD26110043`），同一张订单的多个产品是多行，所以 `记录ID` 会重复出现。

## 参数

| 参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `from_date` / `to_date` | str | 本月 1 号 / 今天 | 日期区间（配合 `date_type`） |
| `date_type` | str | `制单日期` | 日期字段：制单日期 / 订单日期 / 离厂日期 / 交货日期 |
| `filters` | dict | — | **服务端**下拉，见下表 |
| `where` | str | — | 本地过滤，如 `订单状态=编辑中,客户名称~CAR` |
| `key` / `field` | str | `""` | 服务端关键字 + 字段中文名（表单编号 / 客户名称 / 产品名称 / 香港单号…） |
| `key1` / `field1` | str | `""` | 第二组关键字 |
| `columns` | str | 92 列 | 只返回这些列 |
| `limit` | int | 50 | 1~500 |

## 主要列（92 列节选）

**客户单号** / 香港单号 / **表单编号** / **产品名称** / 产品类别 / 装订方式 /
产品类型 / 款数 / 语言数 / 规格 / **订单数量** / 原币单价 / 汇率 / 订单本币金额 /
文件状态 / 样板状态 / 交货日期 / 离厂日期 / 付款期限 / 币种 / 核价否 / **制单日期** /
订单金额 / 需求单号 / 材料状态 / **生产施工单** / 业务员 / 含税单价 / 含税金额 /
发票税额 / 折扣率 / 折后金额 / 内部单价 / 本币折后单价 / 订单产品取消 /
订单产品暂停 / 订单修订 / 改版次数 / 文件附件 / **记录ID**

## 注意

- 2026-11-01~20 实测命中 **48 行**，全量取数请调大 `limit`（上限 500）或导出。
- 金额列有多套口径（订单金额 / 含税金额 / 折后金额 / 折后总金额 / 内部单价），
  报价核对时注意币种与 `汇率`。
- 「生产施工单」列可能是单号也可能是空，取决于是否已转工单。
- 只读接口；订单新建/修改在 ERP 页面上操作。
