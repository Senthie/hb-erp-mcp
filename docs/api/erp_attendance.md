# `erp_attendance` — 月度考勤明细

> 菜单：**人力资源管理 › 考勤管理 › 考勤档案**
> 页面：`RenShi/RS_KQDA_M/Add.aspx`（QXID 2553）｜CLI：`erp attendance`｜**只读**

## 用途

查指定月份的员工考勤（每天一行：上下班时间、迟到/早退分钟、请假、加班等）。

## 参数

| 参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `month` | str | 必填 | 月份 `YYYY-MM` |
| `start_day` | str | `"01"` | 起始日，两位数字 `01`~`30` |
| `end_day` | str | `"30"` | 结束日，两位数字 `01`~`30` |
| `users` | list | 当前账号 | 工卡号或员工姓名；可多个 |
| `limit` | int | 50 | 1~500，超出截断并置 `truncated` |

## 返回

```json
{
  "columns": ["工号", "姓名", "日期", "上班时间", "下班时间", "迟到分钟"],
  "records": [{ "工号": "…", "日期": "2026-11-03", "迟到分钟": "0" }],
  "count": 30,
  "truncated": false
}
```

## 注意

- **日期下拉只有 `01`~`30`**：传 `31` 服务端 200 但只回 1 号一行（看着像"没数据"），
  工具已把日收敛到 `01`~`30`。
- 查**历史月份**要先把页面上的月份切过去（异步回发，带 `__ASYNCPOST` / `X-MicrosoftAjax` 头），
  否则 `txtFXCX=1` 只回 1 号一行、`2` 回 0 行。
- `txtKSTime/txtJZTime` 是**时刻**输入，不是日期区间控件，别混用。
- 账号权限会影响可见人数（实测有的账号 `未离职` 只有 1 条、`全部` 5 条）。
