# `erp_quote_delete` — 删除报价需求单（**会删除 ERP 数据**）

> 菜单：**业务报价管理 › 业务需求 › 客户报价需求 › 列表-客户报价需求**
> 页面：`BaoJia/BJ_KHBJXQ/Add.aspx`｜CLI：—｜**删**

## 用途

按记录 ID 删除一张报价需求单。

## 参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `record_id` | str | 报价需求记录 ID（必填），删除**不可恢复** |
| `confirm` | bool | `false`（默认）只检查单据是否存在并返回单号；`true` 才真正删除 |

## 返回

```json
{ "status": "deleted", "bdbh": "BJXQ261112001" }
```

## 注意

- `confirm=false` 时**不发删除包**，只做存在性检查 —— 建议先跑一次确认单号对了再删。
- 成功标志：重新打开该记录 ID 时 `lblID` 为空（已实现自动复核）。
- 删除后关联的产品明细一并消失，无法通过本工具恢复。
